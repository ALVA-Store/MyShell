# SteamGridDB API Key — MyShell V1

**You only need an API key if you select SteamGridDB as your artwork provider.** HexFlow is an alternative and does not require a SteamGridDB key.

1. Open https://www.steamgriddb.com/ on your phone or computer.
2. Sign up or sign in to your personal account.
3. Visit **Preferences → API**: https://www.steamgriddb.com/profile/preferences/api
4. Generate an API key and copy it accurately. **Use your own key, never someone else's.**
5. On your Vita, launch MyShell, choose a language, and select **SteamGridDB** during the first-run artwork-provider selection.
6. Type the key into the on-screen **SteamGridDB API Key** keyboard and confirm.

**Change your key:** open **Settings → Artwork/Covers**, select SteamGridDB and press **Square (□)** to enter the key again.

The key is saved locally, as plain text, in `ux0:/data/MyShell/config/steamgriddb.key`. Never upload or share the file. The provider choice is stored in `ux0:/data/MyShell/config/artwork_provider.cfg`. Internet access is needed to download art. If a match is missing or the API/service is unavailable, you may choose HexFlow or manual artwork.

SteamGridDB is an independent third-party service: https://www.steamgriddb.com/.
