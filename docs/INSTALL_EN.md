# Install MyShell V1 on PS Vita

## Requirements

- Homebrew-enabled PS Vita with VitaShell.
- Wi-Fi for online artwork, Store, News and information services.
- A personal SteamGridDB API key **only if using SteamGridDB artwork**.
- For launching PSP/PS1 items: the appropriate PSP/PS1 environment plus the independently installed and configured `RETROLNCR` launch helper. MyShell does not install these dependencies.

## Steps

1. Download `MyShell.vpk` from the [Releases Assets](https://github.com/ALVA-Store/MyShell/releases/latest), not from GitHub's autogenerated *Source code* downloads.
2. Transfer the `.vpk` to your PS Vita (USB/FTP via VitaShell).
3. Locate and install it using VitaShell.
4. Open MyShell from LiveArea.
5. Choose your language and select the artwork provider: SteamGridDB or HexFlow.
6. For SteamGridDB, type your own API key into the on-screen keyboard. See [this guide](STEAMGRIDDB_EN.md).

## Library locations

- PS Vita apps/games: scanned in `ux0:/app/`.
- PSP ISO/CSO: `ux0:/pspemu/ISO/`.
- PSP/PS1 EBOOT.PBP: game subfolders of `ux0:/pspemu/PSP/GAME/`.
- Direct PSP launching requires `RETROLNCR` installed at `ux0:/app/RETROLNCR/` and a working PSP/PS1 runtime. MyShell does not supply ROMs, games, Adrenaline or the helper.

See [artwork and music file locations](CONTENT_PATHS_EN.md).

## Troubleshooting

- **Missing games:** check the paths and installed apps, then reopen MyShell to rescan at startup.
- **No SteamGridDB artwork:** verify Wi-Fi and your API key; some games have no matching art. Use HexFlow or manual files instead.
- **Missing songs:** copy `.mp3` or `.wav` to `ux0:/music/`. MyShell also scans up to two nested folder levels. WAV support is PCM stereo 16-bit 44.1 kHz.
- **PSP game fails to launch:** make sure `RETROLNCR` and the PSP/PS1 runtime are available and configured.
- **Store/News offline:** these rely on external third-party services and a working connection.

**MyShell V1 is not an OS replacement.** Its experimental boot/return modules are not part of standard setup. No modification to `ur0:tai/config.txt` is required just to run MyShell from LiveArea.
