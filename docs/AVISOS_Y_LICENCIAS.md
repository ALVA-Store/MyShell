# Avisos de distribución / Distribution notices

**Importante:** Este paquete NO asigna automáticamente una licencia open source. El autor debe decidir si quiere publicar código fuente y con qué licencia, después de comprobar las licencias de todas las dependencias y recursos.

## Pendiente de revisar antes de liberar fuentes o el VPK

- Fuentes bajo `assets/fonts/`, en especial `sst_*.TTF` y `game_title.ttf`.
- Sonidos de interfaz bajo `assets/audio/` y la procedencia/licencia de cada WAV.
- Elementos gráficos bajo `assets/ui/`, `assets/sce_sys/` y posibles marcas/recursos oficiales.
- Código integrado, plugins experimentales, bibliotecas enlazadas y compatibilidad de licencias.
- Atribuciones a quienes aportaron código o arte, en caso de corresponder.

Si no tenés autorización para redistribuir un recurso, **no publiques** el recurso ni un binario que lo incluya hasta resolver el permiso o reemplazarlo por un archivo distribuible. Un aviso de 'fan project' no reemplaza la autorización de uso.

La clave de SteamGridDB de cada usuario es privada. Nunca subir archivos `*.key`, credenciales, tokens ni respaldos de `ux0:/data/MyShell/config/` a GitHub.

**English:** No open-source license is granted automatically. Review all font, audio, UI artwork, third-party code and dependency redistribution rights before publishing source files or bundled VPK assets. A disclaimer alone does not grant permission. Keep personal SteamGridDB keys private.
