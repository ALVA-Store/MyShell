# Changelog

## v1.0.0 — First public release (2026-10-23)

- PS5-inspired PS Vita launcher interface and library carousel.
- PS Vita and PSP/PS1 library scanning and launch integration.
- SteamGridDB API key entry and artwork provider choice (SteamGridDB/HexFlow).
- Per-game manual and downloaded artwork (covers, backgrounds, logos).
- Media music player with MP3 and compatible WAV support.
- Homebrew Store integrated with VitaHomebrewDB catalog.
- News section backed by Reddit public RSS and configurable local cache.
- Game info via Wikipedia/Wikidata, favorites, settings and localization.
- Languages: Spanish, English, Portuguese, German, Italian and Polish.

**Limitations:** No movie/video playback. Not a fully independent OS or total LiveArea replacement. PSP direct launch depends on separately installed `RETROLNCR` helper and PSP runtime. Some online features depend on third-party availability.

**Release validation:** Original VPK ZIP archive tested for integrity; execution on real PS Vita must be confirmed by the publisher before announcing availability.
