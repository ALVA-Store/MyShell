# MyShell — PlayStation Vita

**A modern homebrew shell for PlayStation Vita.**

MyShell is a free, community-focused homebrew project designed to provide a modern and customizable interface for PlayStation Vita.

### Features

- PS Vita, PSP and PS1 game libraries
- Custom artwork and backgrounds
- Integrated homebrew store
- Game information and metadata
- Media library for local movies and music
- YouTube integration (planned)
- Controller and touchscreen navigation

### Media Library

MyShell includes a cinematic media library designed for local video collections.

The project uses Wikipedia and Wikidata for movie information and is developing Fanart.tv integration to retrieve movie posters, transparent logos and backgrounds.

### Project Status

MyShell is currently in active development.

### Availability

MyShell is a free, non-commercial homebrew project for the PlayStation Vita community.

No subscriptions, advertisements or paid features are required.
